# EEG Hat 实验台

八通道 EEG 的本地采集、任务录制、回放、模型训练与在线识别。网页在本机运行，支持运动想象、c-VEP、SSVEP，以及运动想象到 Elite / Piper 机械臂的指令映射。

## 功能与入口

| 页面 | 地址 | 用途 |
|---|---|---|
| 运动想象 | `http://127.0.0.1:8765/` | 静息／左手／右手三分类，CSP、频带功率 + LDA／SVM，机械臂发送 |
| c-VEP | `http://127.0.0.1:8765/cvep` | 2／4／6 目标编码刺激、个人模板校准与识别 |
| SSVEP | `http://127.0.0.1:8765/ssvep` | 8／10／12／14 Hz 四目标刺激、FBCCA 评估与阈值校准 |
| 通用采集与二分类 | `http://127.0.0.1:8765/legacy` | 信号质量、频带反馈、手动标记与个人二分类 |

前三套实验流程固定 **250 Hz、8 通道、μV**，通道顺序为 **O2、O1、P8、P7、C4、C3、FP1、FP2**。GND 和 REF 不计入数据通道。各页面共用设备，切换前停止当前采集或回放。

## 安装与启动

已有 Windows EXE 时，可直接双击根目录 `WanFanEEGHatController.exe`，无需安装 Python。数据位置、联网和迁移方法见 [EXE 使用说明](EXE使用说明.md)。下面为源码运行方式。

推荐 Windows x64、Python 3.12。在仓库根目录打开 PowerShell：

```powershell
cd EEG_Realtime
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-tested.txt
.\.venv\Scripts\python.exe -B -m eeg_realtime.server --open
```

`requirements-tested.txt` 记录本项目验证过的依赖版本；`requirements.txt` 给出兼容版本范围。服务默认只监听 `127.0.0.1:8765`，保持终端打开，按 Ctrl+C 退出。改用其他端口时添加 `--port 8767`，浏览器也使用对应端口。

已配置环境可双击 `EEG_Realtime/启动.bat`。当前开发电脑已配置后台服务，可直接访问上述地址；新电脑需要按上面的步骤启动。启动服务不会自动连接设备、闪烁刺激或发送机械臂动作。

浏览器提示无法访问时，先检查服务终端是否仍在运行及端口是否一致；只读状态地址为 `/api/health`。安装与启动不要求使用特定浏览器或 ChatGPT。

## 连接 EEG Hat

1. 让电脑和 EEG Hat 接入同一局域网。使用 Windows 移动热点时，按厂商配网说明将设备连接到该热点。
2. 关闭 InBrain 或其他软件的设备连接。在网页选择设备信号源，点击发现，选中设备后连接；也可填入热点客户端列表显示的设备 IP。
3. 查看八路波形和收包计数，稳定后再录制。设备 IP 变化时重新发现。

网络使用设备 **TCP / UDP 3333**，电脑接收采集数据用 **UDP 3333**，接收发现回复用 **UDP 3334**。如被防火墙拦截，为实际运行的 Python 配置对应程序、端口和局域网范围的规则。当前电脑的历史网络维护脚本不适用于其他电脑，勿直接复用其中的旧地址和规则。

## 运动想象：录制 → 训练 → 识别

1. **录制**：填写受试者编号和总时长。十字为 2 秒间隔；左箭头、右箭头、圆圈分别提示左手想象、右手想象、静息，每次 5 秒，顺序随机。尾部不足完整任务时只显示间隔。保持提示页面前台可见，结束后查看录制检查结果。
2. **回放**：选中录制，查看八路波形、任务标签和异常位置；录制目录需完整保留。
3. **训练**：停止采集和回放，选择同一受试者、相同配置的有效录制，选择 CSP、频带功率或组合特征，再选 LDA／线性 SVM。每类至少需要 6 个有效完整试次。报告显示有效数据量、排除原因和留出评估结果。
4. **识别**：加载模型，连接与训练来源相同的数据源。每个窗口 **1.5 秒（375 点）**，步长 **0.1 秒（25 点）**，输出类别、置信度和状态。设备通常每包 50 点，结果可随数据包成批更新。

训练与在线处理共用连续因果滤波：平均参考 → 50 / 100 Hz 陷波 → 1–40 Hz 带通。CSP 与特征标准化仅拟合训练数据；概率校准和留出测试使用不同试次。数据充分时按完整录制分组，否则报告明确标注共享录制滤波历史的限制。模拟数据用于检查软件流程，不能与真实设备数据混合训练。

机械臂端的部署和命令见 [robot_pc/README.md](robot_pc/README.md)。左手映射 Elite，右手映射 Piper，静息不发送动作；发送默认关闭。

## 视觉诱发实验

c-VEP 和 SSVEP 均按“连接 → 校准录制 → 评估并保存 → 加载 → 在线识别”操作，录制与模型分别存放。开始刺激需要明确点击并确认页面提示。c-VEP 使用个人相关模板；SSVEP 使用 FBCCA，个人录制用于评估和阈值校准。

详细说明：[运动想象](EEG_Realtime/docs/MI_WORKFLOW.md) · [c-VEP 原理与操作](EEG_Realtime/docs/CVEP_GUIDE.md) · [SSVEP 操作](EEG_Realtime/docs/SSVEP_GUIDE.md) · [设备协议](EEG_Realtime/docs/PROTOCOL.md)。

## 目录与数据

```text
EEG_Realtime/                 服务、网页、运行依赖清单
  eeg_realtime/              采集、录制、回放与在线引擎
  data/                      本机录制、模型、预测及网络配置
  docs/                      操作和技术说明
EEG_Signal_to_Decision/       hat / cvep / ssvep 算法模块与 MI 训练 CLI
robot_pc/                    Linux 机械臂接收器与两个动作脚本
windows_exe/                 Windows EXE 入口与构建配置
WanFanEEGHatController.exe   本机生成的单文件程序，不随 Git 提交
InBrain/、其他 EXE / PDF      本机保留的厂商应用与参考资料
```

录制、模型和预测分别位于 `EEG_Realtime/data/` 下的 `mi_*`、`cvep_*`、`ssvep_*` 目录。移动录制时复制整段目录；备份时保留整个 `data/`。模型文件仅加载可信来源。

根 `.gitignore` 默认排除个人数据、模型、日志、本机依赖和配置脚本，以及厂商应用、EXE、PDF；这些文件仍保留在本地。复制源码时同时保留 `EEG_Realtime` 和 `EEG_Signal_to_Decision` 的相对位置，已有模型依赖其模块路径。

设备协议不提供逐样本硬件时间戳，标签对齐使用软件时钟估计。离线分数只对应所用数据，实际受试者分类效果、显示器光输出及机械臂轨迹需另行实测。
