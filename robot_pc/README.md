# 机械臂接收端

将本目录复制到 Linux 机械臂电脑，三个 Python 文件保持同目录。使用原先能够运行 Elite、Piper 动作的 Python 环境；推荐 Python 3.10 或以上。

## 准备

- Elite 需要提供 `from elite import EC` 的 SDK，以及控制器网络连接。此仓库未记录该 SDK 的安装版本，请沿用已验证环境。
- Piper 需要 `piper_sdk` 和已配置的 CAN 接口。默认使用 SDK 的接口设置，也可通过 `--piper-can can0` 指定。
- EEG 电脑与接收电脑之间需可达 UDP 5005，两端系统时间需同步；消息包含有效期。

先检查脚本语法和模块是否存在：

```bash
cd /你的路径/robot_pc
python3 receiver.py --check
```

此检查不初始化 SDK，不连接机械臂。

## 仅验证通信

将命令中的 `<EEG电脑IP>` 替换为实际地址：

```bash
python3 receiver.py --sender-ip <EEG电脑IP> --port 5005
```

默认 dry-run，只接收并回执，不执行动作。省略 `--sender-ip` 时只接受本机消息。

在 EEG 网页的“在线识别与机械臂”中填入**接收电脑 IP** 和端口 5005，点击通信测试，查看 TEST 回执。此处不填写 EEG 帽或 Elite 控制器的 IP。本机查看分类可使用“仅预览映射”，无需连接接收电脑。

## 启用动作

动作脚本包含既定点位、速度和夹爪参数。先由操作者核对现场布局、实体急停，并完成各机械臂的单机验证，再停止 dry-run 接收器，启动执行模式：

```bash
python3 receiver.py --sender-ip <EEG电脑IP> --port 5005 --execute --elite-ip <Elite控制器IP>
```

`--elite-ip` 省略时使用 `ELITE_ROBOT_IP`，再回退到脚本默认 `192.168.137.200`；Piper 可附加 `--piper-can can0`。

EEG 网页加载个人实机模型并连接设备，保持页面聚焦，再点击“启用机械臂发送”。

| 模型结果 | 兼容命令 | 动作 |
|---|---|---|
| 左手运动想象 | `CLENCH` | `eat_elite.py`，Elite |
| 右手运动想象 | `BLINK` | `drink_piper.py`，Piper |
| 静息 | 无动作包 | 待机 |

当前版本逐窗采用模型候选类别，不以置信度或累计票数作为发送门槛；最近 15 窗计数仅供观察。无模型、预热、平线、饱和或无效数据不会产生动作指令。

接收端保留 **25 秒冷却**，动作仍在执行时继续拒收新动作；忙碌请求直接丢弃，不排队、不重试。持续预测同一动作时，冷却结束后可再次触发。执行失败会锁定后续动作，排查后再重启接收器。

超过 1 秒未收到 EEG、预测窗口超过 0.5 秒、页面心跳超过 2 秒，或页面失焦、隐藏、切换模型等情况会停发。网页显示停发原因，日志在 `EEG_Realtime/data/mi_robot/`。**停止发送仅停止后续指令，已开始的动作需使用机器人自身的停止控制。**
