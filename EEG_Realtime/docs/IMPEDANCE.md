# 00 电极阻抗检查

本页记录本仓库阻抗检查的协议依据、厂商参数及验证边界。协议来源为仓库根目录的《万帆科技8通道EEG下位机通信协议.pdf》（v1.0，整理日期 2026-05-20）。

## 协议依据

| 项目 | 协议位置 | 规则 |
| --- | --- | --- |
| 控制与数据端口 | 第 4 节 | TCP 控制、UDP 数据均为 3333；数据目标为 TCP 客户端 IP |
| 进入阻抗 | 6.3.5、12.1 | TCP 发送 `5A 05` |
| 回到普通 EEG | 6.3.2、12.2 | TCP 发送 `5A 02` |
| 停止 | 6.3.3 | TCP 发送 `5A 03`，TCP 会话保留 |
| 模式切换 | 12.3、12.4 | 重新初始化 ADS1299，UDP 短暂停顿，包序号从 0 重启；两种模式数据格式相同 |
| ADC 换算 | 11.1、11.2 | 大端有符号 24 位；`uV = raw * (4.5 / 24 / 8388607) * 1e6` |
| 阻抗激励 | 12.5.1 | AC lead-off，24 nA、7.8 Hz |
| 阻抗换算 | 12.5.2 | 每通道窗口去均值后计算总体 RMS；`Z_kohm = RMS_uV * sqrt(2) / 24 * 1.32` |
| 异常接触 | 12.5.3 | 接近饱和或 RMS < 0.2 µV 时显示上限 250 kΩ |
| 时序 | 16.2 | CONFIG 后等待约 100–300 ms，再发送 START；切换保留短暂等待 |
| 可观测状态 | 第 19 节 | 无命令 ACK，无独立状态包，无 UDP 模式字段；模式由上位机最后发送的命令维护 |
| 会话关闭 | 14.3、15.1 | TCP 断开时停止采集、清除 UDP 目标，并继续监听新的 TCP 连接 |

阻抗计算使用未经过 EEG 带通、陷波或 AI 去噪的数据。UDP 解码与普通 EEG 共用协议解析器，保留 CRC 检查。切换和断流后的窗口重新积累，避免不同采集阶段的数据混入同一阻抗结果。

## 厂商软件的静态核验

核验对象：`InBrain/InBrain_APP.exe`。

SHA256：`f2ead6f43fcdbce91874557e7695f0a26ef9a7c2476388e0e10388ea6fbfca87`。

以下参数通过该文件保留的 C++ 符号、反汇编及只读数据段核对。地址为该文件的虚拟地址，仅适用于上述哈希版本。

| 参数 | 已核验行为 | 位置 |
| --- | --- | --- |
| 模式控制 | 开启发送 `5A 05`，关闭发送 `5A 02` | `MainWindow::setupConnections` 的 bool lambda，`0x140012b00`；开启分支 `0x140012cd0` |
| 窗口 | `max(sample_rate, 500)` 个样本；250 Hz 为 2 秒，500 Hz 及以上为 1 秒 | `DataProcessor::setSampleRate`，`0x1400bb46c–0x1400bb4a8` |
| 更新间隔 | 累计样本达到 `sample_rate // 2` 后计算，计数归零 | `DataProcessor::processBufferedData`，`0x1400c40ac–0x1400c40ef` |
| 饱和门限 | 窗口原始 `max(abs(uV)) > 170000`，包含 DC 分量 | 同函数 `0x1400c451e`；float 常数 `0x14016bbd0` |
| 低 RMS 门限 | RMS < 0.2 µV | 同函数 `0x1400c4530`；float 常数 `0x14016bbd4` |
| 换算与上限 | RMS 乘 sqrt(2)、除 24、乘 1.32，最后取 `min(value, 250)`；异常分支也为 250 | 同函数 `0x1400c453d–0x1400c4565`；double 常数 `0x14016bbd8`、`0x14016bbe0`、`0x14016bbe8`、`0x14016bb50` |
| 显示 | 一位小数，后缀 `k`；负值显示 `OFF` | `TimeDomainWidget::updateImpedanceValues`，`0x1400d9d10` |

厂商分档常数位于 `0x1401702e8`（5）、`0x140170300`（10）、`0x140170318`（25）。分档边界包含上限：

| 阻抗 kΩ | 圆点 RGB | 文本 RGB |
| --- | --- | --- |
| ≤5 | `#2ecc71` | `#27ae60` |
| >5 且 ≤10 | `#a2d94c` | `#82b432` |
| >10 且 ≤25 | `#f1c40f` | `#d4ac0d` |
| >25 | `#e74c3c` | `#c0392b` |

颜色常数按表中次序位于 `0x1401702f0` 至 `0x140170338`，每个常数包含 4 个 16 位 ARGB 分量。以上分档是厂商显示规则，不是医学判定阈值。

## 软件验证与实机验收

本地传输测试位于 `EEG_Realtime/tests/test_impedance_transport.py`。测试使用回环 TCP/UDP 模拟设备，检查 CONFIG、普通 EEG/阻抗 START、模式切换 STOP、CRC 拒绝、序号归零、切换期间旧包清空和超时 STOP/START 恢复；不连接电极帽。可在项目依赖已安装的 Python 环境执行：

```powershell
python -m unittest discover -s EEG_Realtime/tests -p 'test_impedance_transport.py' -v
```

2026-11-01 的实现后检查中，上述 3 项本地传输测试通过；数值估计、窗口有效性、会话生命周期及两个 HTTP 控制器的测试也通过。全套测试从 `EEG_Realtime` 目录运行：

```powershell
python -m unittest discover -s tests -p 'test_impedance*.py' -v
node tests/test_impedance_frontend.cjs
```

前端测试覆盖读数过期、请求延迟、模式切换期间的旧响应竞争及停止重试；浏览器检查另验证了默认 01 模拟采集启停、00 八通道布局，以及隔离模拟输入下的阻抗 / EEG 双向切换、窗口积累和数值显示。

[Unverified] 本次静态核验和软件测试未验证真实电极帽的测量结果、无线网络时序或与 InBrain 实机读数的一致性。实机验收仍需连接同一设备，分别在本控制台和 InBrain 中检查相同电极接触条件下的各通道读数、模式往返、断开电极和断网重连表现。两款上位机需分别运行，避免争用 UDP 3333 或单客户端 TCP 会话。

协议 12.5.4 将此算法定位为电极接触质量评估，并注明结果未经过严格医学计量标定。界面中“已发送启动命令”和“收到有效数据”分别对应本机发送动作和 UDP 接收事实；协议无法提供独立的设备模式确认。
