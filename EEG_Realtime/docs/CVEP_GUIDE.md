# c-VEP：原理与操作

启动方法见[根目录说明](../../README.md)。入口为 <http://127.0.0.1:8765/cvep>。

## 工作原理

c-VEP 用不同的亮暗编码区分屏幕目标。受试者注视一个目标，系统采集其视觉诱发响应，再将新脑电与该受试者的各目标模板比较。

本地支持 **2、4、6 个目标**，默认 6 个。每个目标使用一组 63 位 Gold 编码，每位保持 2 帧；60 Hz 下一个周期为 126 帧、约 2.1 秒。脑电响应包含视觉系统延迟及背景活动，因此需要个人校准及刺激相位对齐。

`目标编码 → 屏幕刺激及逐帧记录 → 八通道 EEG → 滤波与相位对齐 → 个人模板相关 → 候选目标或不确定`

c-VEP 依赖编码的时间结构。运动想象数据和模型无法直接用于该流程；SSVEP 则通过不同频率区分目标。

## 与 ArmBCIsys 论文的关系

[ArmBCIsys 论文](https://doi.org/10.1109/TNNLS.2025.3579332) 第 8–9 页给出视觉实验参数，网络结构见第 3–5 页。本机根目录保留 PDF 副本，公开库不包含该文件。

| 项目 | 论文 | 本地实现 |
|---|---|---|
| 目标 | 六组 Gold 编码 | 可选 2 / 4 / 6 组本地编码 |
| 呈现 | 60 Hz 显示器，Python/Pyglet | 浏览器刷新帧驱动，录前检查约 60 Hz |
| 编码长度 | 写明刺激长度为 126 | 明确定义为 63 位 × 每位 2 帧 |
| 采集 | OpenBCI Cyton，250 Hz | EEG Hat，250 Hz |
| 解码电极 | O1、Oz、O2、PO3、POz、PO4 | O2、O1、P8、P7 |
| 预处理 | 4–40 Hz 带通、45–65 Hz 陷波、降至 125 Hz | 4–40 Hz 因果带通、50 Hz 陷波，保留 250 Hz |
| 解码器 | DBFENet：时域卷积与 DCT/Transformer 频域分支 | 个人多通道相位模板相关 |

本地代码保存明确的编码序列、生成规则和哈希；“63 位 × 2 帧”是本地协议选择。当前没有实现 DBFENet，也不采用论文报告的准确率作为本系统结果。P7/P8 与论文的 PO3/PO4 位置不同，当前帽子还缺少 Oz/POz，需使用本帽重新采集个人数据。

论文的视觉分割、物体定位和机械臂控制属于后续模块。本地 c-VEP 仅显示目标识别结果；机械臂连接位于运动想象工作台。

## 校准录制

1. 停止其他工作台及 InBrain 的设备连接。在 c-VEP 页面选择模拟源检查流程，或连接真实设备。
2. 选择目标数，填写稳定的受试者身份、本次录制名和每个目标的试次数。
3. 完成显示刷新率和时钟检查，阅读页面闪烁提示后开始。实机需至少 2 秒连续新鲜 EEG，且必需通道通过硬质量检查。
4. 每次先显示 **2 秒静态提示**，随后所有目标同时闪烁 **3 个周期、约 6.3 秒**。按提示注视指定目标；每轮各目标出现一次，顺序随机。
5. 保存后查看每目标有效试次数与排除原因。累计每目标至少 **6 个有效完整试次**，再停止采集并训练。

默认每目标 6 次。2 / 4 / 6 目标对应 12 / 24 / 36 次，名义时长约 100 / 199 / 299 秒，另有检查与保存耗时。

| 字段 | 用途 | 同一受试者的多轮示例 |
|---|---|---|
| 受试者身份 `subject` | 合并个人数据时核对身份 | 各轮均填 `S01` |
| 录制名 `recording_name` | 区分轮次 | `S01_01`、`S01_02` |
| 录制 ID `id` | 唯一保存目录及分组标识 | 自动生成 |

可合并身份、来源、目标数及编码契约一致的校准录制。录制名不作类别或身份依据；软件不会自动把旧身份编号末尾的数字去掉。已有文件的身份更正需先核实来源并备份，不改原始样本和标签。

## 模板、评估与在线识别

系统保存全部八通道原始 μV 信号，解码选用 O2、O1、P8、P7。连续滤波后，按实际帧时间计算编码相位；首个周期用于预热，后续完整窗口用于训练或预测。

每目标至少 6 个有效试次。按时间顺序将完整试次分为训练、校准和测试；6 次时为 4 / 1 / 1。训练组估计模板，校准组设置拒识阈值，测试组生成报告。重叠窗口及周期跟随所属试次分组；同一录制的不同试次可能进入不同集合，报告不等于跨录制泛化评估。

加载当前受试者、来源和目标数匹配的模板后，启动在线自由注视。首个结果约在刺激开始 3.6 秒后出现，随后每 0.1 秒比较最近 1.5 秒脑电与各目标模板。页面显示最佳目标、相关分数和与次佳目标的差值；这些分数不是正确概率。

休息或新试次积累期间显示等待状态；在线自由注视没有真实目标标签，预测不会写回训练标签。当前一次在线运行 12 个试次，可提前停止。该模型没有单独训练“不注视”或静息类别。

查看留出准确率时，应同时查看混淆矩阵、有效试次数、覆盖率和拒识率。均衡随机猜测基准为 2 类 50%、4 类 25%、6 类约 16.7%；真实效果需用个人数据和新录制评估。

## 时间证据、回放与存储

帧时序超限会告警、继续保存 EEG，并排除受影响试次；后续试次独立检查。页面失焦、隐藏、请求失败、帧序错误和采集硬故障等仍会中止。详细条件见[目标数与录制中断](CVEP_TARGETS_AND_INTERRUPTS.md)，排查步骤见[常见问题](CVEP_TROUBLESHOOTING.md)。

软件逐帧记录无法测量屏幕实际发光时刻，也无法单独测出帽子缓存及固定无线延迟。需要物理同步精度时，应使用光电传感器或硬件触发测量。

数据位于 `EEG_Realtime/data/cvep_recordings/`，模板位于 `cvep_models/`，在线结果位于 `cvep_predictions/`。备份录制时保留完整目录。回放只显示八通道脑电和原有目标标注，不重新闪烁。

已知有光敏性癫痫或闪烁诱发不适者勿用；出现不适立即按 Esc 或停止。页面需明确操作才开始刺激。
